\hypertarget{index_Description}{}\doxysection{Description}\label{index_Description}
This program runs a series of tests on a classic mergesort and a threaded mergesort. Once the tests are completed, it builds a table of timings comparing the classic and threaded merge sort.

Make Commands\+: \begin{DoxyVerb}make
\end{DoxyVerb}
 will build the executable. \begin{DoxyVerb}make run
\end{DoxyVerb}
 will run the experiments. \begin{DoxyVerb}make clean
\end{DoxyVerb}
 will clear out the compiled code. \begin{DoxyVerb}make doc
\end{DoxyVerb}
 will build the doxygen files.
